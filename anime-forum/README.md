# AnimeForum - Аниме Форум

Полноценный frontend аниме-форума с современным дизайном, glassmorphism эффектами и адаптивной вёрсткой.

## 🎌 Особенности

- **Современный UI/UX дизайн** с яркими градиентами (розовый, фиолетовый, голубой)
- **Glassmorphism эффекты** для карточек и панелей
- **Тёмная/Светлая тема** с сохранением в localStorage
- **Адаптивный дизайн** (mobile-first подход)
- **Плавные анимации** при наведении и переходах

## 📄 Страницы

### Главная страница
- Список категорий форума (5 категорий)
- Статистика форума (онлайн пользователи, темы, сообщения)
- Фильтр по категориям
- Сортировка тем (по дате, популярности, ответам)
- Последние активные темы

### Страница темы
- Просмотр всех постов в теме
- Аватарки и статусы пользователей
- Дата создания поста
- Кнопки ответа и цитирования
- Реакции (лайки) с подсчётом
- Форма быстрого ответа
- Хлебные крошки навигации

### Профиль пользователя
- Аватарка с индикатором статуса
- Статистика (сообщения, репутация, дата регистрации)
- Любимые аниме с обложками
- Подпись пользователя
- Бейджи и достижения
- Недавняя активность

## 🔧 Функционал

- ✅ Переключение между страницами (SPA)
- ✅ Создание новых тем
- ✅ Ответы в темах
- ✅ Цитирование постов
- ✅ Лайки/реакции
- ✅ Поиск по темам
- ✅ Фильтрация по категориям
- ✅ Сортировка тем
- ✅ Сохранение данных в LocalStorage
- ✅ Переключение темы оформления

## 📊 Mock-данные

В проекте используются следующие mock-данные:

- **10 пользователей** с аватарками, статистикой и любимыми аниме
- **5 категорий** форума
- **20 тем** с тегами и метаданными
- **50+ постов** автоматически генерируемых для тем
- **10 аниме-цитат** для отображения в футере

## 🚀 Запуск

Просто откройте файл `index.html` в любом современном браузере:

```bash
# Вариант 1: Прямое открытие
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux

# Вариант 2: Локальный сервер (рекомендуется)
python -m http.server 8000
# Затем откройте http://localhost:8000
```

Или используйте Live Server в VS Code.

## 🎨 Цветовая схема

### Светлая тема
- Primary: `#ff6b9d` (розовый)
- Secondary: `#c445f0` (фиолетовый)
- Accent: `#00d4ff` (голубой)
- Background: `#f5f7fa`

### Тёмная тема
- Background: `#0f1419`
- Cards: `#1a1f2e`
- Text: `#f7fafc`

## 🛠 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - Custom Properties, Grid, Flexbox, Animations
- **Vanilla JavaScript** - без фреймворков
- **Font Awesome** - иконки
- **LocalStorage** - хранение настроек и данных
- **Pravatar.cc** - аватарки пользователей
- **Picsum.photos** - изображения для любимых аниме

## 📱 Адаптивность

Проект полностью адаптирован под мобильные устройства:

- Mobile: < 480px
- Tablet: 480px - 768px
- Desktop: > 768px
